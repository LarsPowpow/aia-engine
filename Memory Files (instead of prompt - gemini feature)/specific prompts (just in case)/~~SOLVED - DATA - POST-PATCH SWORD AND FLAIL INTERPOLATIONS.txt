### **Objective:**
Create a set of functions to accurately predict the in-game UI damage for the Sword and Flail weapons in New World, based on a provided set of post-patch attribute data tables.

### **Core Methodology: The Interpolation Table Model**
The damage calculation is not based on a single continuous formula. Instead, it relies on linear interpolation between a series of known data points ("anchor points"). The total UI damage is the sum of the weapon's base damage and the damage added by each of its scaling attributes.

The formula is:
`Total Damage = Base Damage + Added Damage (Primary) + Added Damage (Secondary)`

Where:
-   **Base Damage:** A constant value for each weapon at 5 attribute points.
-   **Added Damage:** The damage gained from an attribute above the baseline of 5. This value must be calculated for each relevant attribute by finding its contribution from the data tables.

### **Implementation Steps:**

1.  **Store the Data:** The provided data tables are the source of truth. Store them in a suitable data structure (e.g., arrays of objects, dictionaries).
2.  **Create an Interpolation Function:** Write a generic linear interpolation function `interpolate(targetX, x1, y1, x2, y2)`. This function will calculate the `y` value at `targetX` on the line between points `(x1, y1)` and `(x2, y2)`.
3.  **Create Attribute Damage Functions:** For each of the four data tables, create a specific function (e.g., `getSwordStrDamage(strengthPoints)`) that:
    a. Takes an attribute value as input (e.g., 350 STR).
    b. Finds the two closest anchor points in the corresponding data table that bracket the input value.
    c. Uses the `interpolate` function to find the UI Damage at that exact attribute value.
    d. Subtracts the weapon's Base Damage from the result to get the `Added Damage` for that attribute.
4.  **Create a Master Calculator Function:** Create a main function, `calculateDamage(weaponType, str, dex, foc)`, that:
    a. Takes the weapon type and all relevant attributes as input.
    b. Sets the correct `Base Damage` based on the weapon type.
    c. Calls the appropriate attribute damage functions (e.g., for "Sword", it would call `getSwordStrDamage(str)` and `getSwordDexDamage(dex)`).
    d. Sums the `Base Damage` and all calculated `Added Damage` values to get the final predicted UI damage.
    e. Returns the final, rounded integer value.
