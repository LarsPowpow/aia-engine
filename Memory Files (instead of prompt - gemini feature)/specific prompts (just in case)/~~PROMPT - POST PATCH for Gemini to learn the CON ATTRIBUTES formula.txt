### **Objective:**
Create a function to accurately predict a player's total Health Points (HP) in New World based on their Constitution (CON) attribute.

### **Core Methodology: The Interpolation Table Model**
The HP calculation is not based on a single continuous formula. Instead, it relies on linear interpolation between a series of known data points ("anchor points"). The relationship between CON and HP exhibits diminishing returns at specific breakpoints.

### **Implementation Steps:**

1.  **Store the Data:** The provided `CON_HP_TABLE` is the source of truth. Store it in a suitable data structure (e.g., an array of objects or a dictionary) that can be easily accessed.
2.  **Create an Interpolation Function:** Write a generic linear interpolation function `interpolate(targetX, x1, y1, x2, y2)`. This function will calculate the `y` value (HP) at `targetX` (the desired CON value) on the straight line between the two closest anchor points `(x1, y1)` and `(x2, y2)`.
3.  **Create the Calculator Function:** Write a main function, `calculateHP(constitutionPoints)`, that:
    a. Takes a single integer `constitutionPoints` as input.
    b. Finds the two closest anchor points in the `CON_HP_TABLE` that bracket the input value. For example, if the input is `67`, the bracketing points are `50` and `99`.
    c. Passes these two anchor points and the target CON value to the `interpolate` function.
    d. Returns the final, rounded integer value for the predicted HP.
